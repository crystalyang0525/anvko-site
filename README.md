# AVNKO Studio — Website

Professional photography studio website for anvko.ca

## Deployment

This site is hosted on GitHub Pages with a custom domain (www.anvko.ca).

## File Structure

- `index.html` — Homepage
- `studio-rental.html` — Studio Rental page
- `portfolio.html` — Portfolio page
- `about.html` — About page
- `contact.html` — Contact page
- `studio1.jpg` — Studio photo 1
- `studio2.jpg` — Studio photo 2 (5-panel)
- `anvko_logo.svg` — Brand logo

## To Update

Edit the relevant HTML file and re-upload to this repository. Changes go live within 1–2 minutes.
